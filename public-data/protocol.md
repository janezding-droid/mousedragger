# 公開資料固定實驗協議 v1

凍結：2026-11-04，第 1 輪；尚未讀取 public_labels.csv 或任何 test session。種子 20261104。後續改動須記錄版本與是否受測試結果影響。

## 研究問題及單位

Balabit：現有純幾何特徵能否可靠描述外部 RDP 滑鼠操作？冒用偵測是合法／冒用問題，不是 bot 辨識。原始 session 是切分、聚合及不確定性單位；按鈕 Pressed 到同按鈕 Released 的完整片段為特徵單位，不造起終事件、TARGET、同意或完成真值。先研究 training_files，每個使用者依完整路徑字典序取前四個 session（不足全取），不按結果篩選。官方 training session 為帳戶合法擁有人操作；來源操作人以官方可追溯身分為準。

主時間採 record timestamp（秒），減去片段起始再乘 1000，保留 client timestamp 供稽核。僅完整左右按鈕片段；只接受內部 Move/Drag，Scroll 事件可保留於原始來源但不計入軌跡。未知狀態、中途按壓、無起點、錯誤配對、負／倒序時間、非有限座標、零時長、超過 180 秒或 2500 事件均明確記錄排除原因，不修成正常資料。同時間事件保留且沿用 canonical features 規則。不將自由移動任意包成拖曳。

## 切分與洩漏

開發批次每人四個 session 中，前二 train、第三 validation、第四 reserved；不足時保留可用集合且揭露。reserved 目前不做分類測試；資料品質可全批檢查，分類方法選擇不可使用其結果。以整個 session 分組，不使用重疊視窗。產出 session SHA-256 及去起始時間後事件指紋；跨集合精確重複必須隔離或合併至同組後才評分。近重複與 test 冒用來源重用仍需額外檢查，未驗證不能聲稱無洩漏。

未來 participant holdout 預設 user35、user7、user9（字典序最後三人），不可用於調參；每個帳戶內 session 切分不等於未見使用者泛化。官方 public test 來源使用者未知；先對原始及平移／時間正規化片段查重，無法復原的來源身分明確列 unknown。不能以 claimed account 當冒用來源使用者。public labels 僅於固定最終評估時載入，不能調閾值。

## 方法、指標、參數及不確定性

先做描述性品質、拒收比例、缺值、同時間段與 session 特徵分布。分類待來源與樣本檢查後，比較正常樣本標準化距離及 L2 logistic regression，另列隨機機會水準；正類=冒用。標準化、閾值及模型只在 train/validation 擬合；候選 L2 C={0.1,1,10}，距離用 training 中位數/IQR，validation 固定 FPR 5% 閾值，若無法估計則不報該指標。test 報 ROC-AUC、PR-AUC、FPR、FNR、類別比例；沒有雙類標籤不產生成績。消融速度、停頓、幾何組。session 中位數聚合；信賴區間以使用者叢集 bootstrap 2000 次（種子固定），小樣本列限制，不能把片段當獨立樣本。

穩健性固定為每隔一事件降採樣、座標乘 0.5/2、固定種子時間抖動（幅度 5ms 後單調約束）、固定種子移除 5% 內部事件，起終點保留。敏感度 pause threshold=5/10 px/s，最大片段時長=60/180s；衍生資料保留原始來源，非法負值/倒序另做拒收測試。結果不得與原始資料混算。

## DARPA 與資源

優先 E3 TRACE，須下載官方攻擊說明、CDM schema 與可負擔原始事件批次後才選案例；原始事件以 UUID/來源檔及行號追溯。時間單位由 schema 核對，禁止猜測。對照原始事件、精確去重、依 subject/object/type/time bucket 聚合（1s/10s），摘要保留所有原始事件 ID 與最小／最大時間。攻擊保留僅在已對應官方真值範圍評分；背景未標註為 unknown，不能算正常。跨主機／時間 holdout 視可取得範圍決定，後續新增協議版本先於評估。原始下載累計預設上限 5,000,000,000 bytes，單檔先查大小，未知大小不上大包；單輪約 45–50 分鐘。不得執行資料中的程式。

重跑固定 Node 與 Python 版本及依賴鎖；乾淨輸出對比計數／特徵容差。三規模分開量測冷啟動與重複 wall time/峰值記憶體。來源授權不明不再散布原始資料。Q1–Q6 逐項證據及尚未驗證範圍見 quality-status.json。
